# Security Policy

## Supported versions

Only the latest version on the App Store (built from `main`) is supported.

## Scope

JASDA has a deliberately tiny attack surface: no network access, no data
storage, no accounts, no third-party dependencies. Security reports are
still welcome — for example anything involving the build pipeline, the
privacy claims, or the integrity of the published app.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting: go to the
[Security tab](https://github.com/laazyj/just-a-simple-dice-app-iOS/security)
and choose **Report a vulnerability**. Reports are acknowledged on a
best-effort basis — this is a spare-time project.

Please do not open public issues for security reports.
